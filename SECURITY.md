# Security Policy

## Supported versions

Only the latest release on `main` receives security fixes.

## Reporting a vulnerability

Please **do not open a public issue** for security problems. Report them privately to the
repository owner (via GitHub's private vulnerability reporting when the repository is public, or by
contacting the owner through their GitHub profile). Include steps to reproduce, impact, and any
proof of concept.

You can expect an acknowledgement within 7 days. Good-faith research that avoids privacy
violations, data destruction and service disruption is welcome, and will be credited in the
changelog if you wish.

## Acceptable use

Argus is for **authorised** security research, bug bounty programmes within their published
scope, CTFs, education, and assessment of infrastructure you own. Every scan requires a stated
purpose and confirmation of authorisation, and is recorded in a tamper-evident audit log.
Using Argus against systems or people without permission may be illegal (e.g. the UK Computer
Misuse Act 1990) and is not supported.
